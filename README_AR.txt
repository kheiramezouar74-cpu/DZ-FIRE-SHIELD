DZ-FIRE SHIELD — واجهة عربية تجريبية

الملفات:
- app.py: واجهة Streamlit عربية.
- requirements.txt: المكتبات اللازمة.
- ضع نموذج YOLO المدرب باسم best.pt في نفس المجلد لتفعيل الكشف.

التشغيل على حاسوب:
1. تثبيت Python.
2. افتح الطرفية داخل المجلد.
3. نفّذ: pip install -r requirements.txt
4. نفّذ: streamlit run app.py

التشغيل على الهاتف:
يمكن استعمال Google Colab أو خدمة استضافة تدعم Streamlit، لكن تشغيل خادم Streamlit محلياً على Android ليس مضموناً.
أسهل طريقة أولية: رفع الملفات إلى مستودع GitHub ثم نشر التطبيق على Streamlit Community Cloud.
يلزم إنشاء حسابات المستخدم بنفسه والموافقة على شروطها.

مهم:
- بدون best.pt، الواجهة تقبل الصورة لكنها لا تدّعي أنها حللتها.
- لا توجد بيانات أو نتائج تدريب مضمنة.
- لا ترسل تنبيهات حقيقية ولا تتصل بالدرون أو الحماية المدنية.
- يجب اختبار النموذج على بيانات مستقلة ومراجعة كل نتيجة بشرياً.
